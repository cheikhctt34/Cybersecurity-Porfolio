
# Module 02 – Footprinting and Reconnaissance

**Course:** Certified Ethical Hacker (CEH) v13  
**Provider:** EC-Council  
**Volume:** 1  
**Duration:** 2 Hours 30 Minutes  
**Status:** Completed

## 1. Project Overview

This lab focused on Footprinting and Reconnaissance, an important stage of ethical hacking and penetration testing.

The objective was to understand how publicly available information can be collected about an organization using search engines and advanced search operators.

## 2. Lab Objectives

- Understand Open-Source Intelligence (OSINT).
- Perform information gathering using Google.
- Explore advanced Google search operators.
- Identify publicly indexed organizational information.
- Understand how information exposure can create security risks.

## 3. Lab Environment

- Operating System: Windows 11
- Browser: Mozilla Firefox
- Search Engine: Google
- Training Environment: EC-Council Virtual Lab

## 4. Technical Skills and Techniques

The lab introduced the following Google search operators:

| Operator | Purpose |
|---|---|
| site: | Search within a specific domain |
| intitle: | Search words in page titles |
| filetype: | Find specific document types |
| inurl: | Search terms within URLs |
| allintitle: | Search multiple title keywords |
| inanchor: | Search link anchor text |

## 5. Practical Exercises

Example search queries explored:

```bash
site:eccouncil.org intitle:login

site:eccouncil.org filetype:pdf ceh

site:eccouncil.org inurl:career
```

These techniques demonstrate how publicly accessible information can be identified during authorized reconnaissance.

## 6. Cybersecurity Concepts

- Open-Source Intelligence (OSINT)
- Digital Footprinting
- Information Gathering
- Search Engine Reconnaissance
- Attack Surface Awareness
- Public Information Exposure

## 7. Security Implications

Information unintentionally exposed through search engines can help attackers understand an organization's online presence.

Security professionals can use these techniques to identify unnecessary public exposure and recommend improvements.

## 8. Key Learning Outcomes

Developed an understanding of how search engine operators support reconnaissance and how publicly accessible information can contribute to organizational security risks.
